# مقاطع تيك توك من بودكاست معالم

يستخرج هذا الخط الإنتاجي مقاطع عمودية (9:16) من حلقة *الطريق إلى الله — أ.د. عبدالله
العسكر* (بودكاست معالم)، مع ترجمة عربية محروقة داخل الفيديو بخط **ثمانية الرقمي
(Thmanyah Sans)** وتفعيل **الكشيدة**.

## المكوّنات

| الملف | الوظيفة |
|------|---------|
| `fetch_thmanyah.py` | يجلب خط ثمانية الرقمي وقت البناء للعرض فقط (لا يُرفع الخط للمستودع؛ ترخيص الخط يمنع إعادة النشر). |
| `kashida.py` | يضيف الكشيدة (التطويل ـ) في مواضعها الصحيحة — تطويل واحد لكل كلمة — بقياس عرض النص عبر HarfBuzz. |
| `render_layer.py` | يرسم العنوان والترجمة كصور شفافة عبر Pillow + raqm (تشكيل عربي صحيح)، ويبني شريط الترجمة على المحور الزمني. |
| `build_final.py` | يركّب كل مقطع: خلفية مموّهة عمودية + الفيديو + طبقة النص، في تمريرة ffmpeg واحدة. |
| `captions.ar.srt` | الترجمة العربية التلقائية للحلقة (مصدر التوقيت والنص). |

## المقاطع الخمسة

1. **العقل قد يقودك إلى الهاوية** — قصة الإمام الرازي والعجوز.
2. **قمة الرضا تسليمُ أمرك لله** — قصة الخسروشاهي.
3. **أُصدّقه في خبر السماء** — موقف أبي بكر من الإسراء والمعراج.
4. **لا تحزن إنَّ الله معنا** — قصة الغار.
5. **كلَّا إنَّ معي ربي سيهدين** — موسى والبحر.

## التشغيل

يعمل الخط الإنتاجي عبر GitHub Actions (`.github/workflows/extract-clips.yml`):
يحمّل نوافذ المقاطع من يوتيوب بصيغة HLS (تتجاوز حماية SABR)، ثم يرندر المقاطع
ويرفعها كـ artifact باسم `tiktok-clips`.

> ملاحظة: تُستخدم صيغة HLS لأن يوتيوب يفرض SABR على الصيغة التقدّمية (itag 18)؛
> كما يُستعمل مزوّد PO Token (bgutil) وحلّال تحدّي JS عبر Node 22.
