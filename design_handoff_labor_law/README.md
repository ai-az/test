# حزمة التسليم — تصميم «نظام العمل» (Hallmark Specimen)

> **للمطوّر / Claude Code:** الملفات المرفقة في هذه الحزمة هي **مراجع تصميم مكتوبة بـ HTML/React-Babel** — نماذج توضّح الشكل والسلوك المقصودين، وليست كوداً جاهزاً للنسخ المباشر إلى الإنتاج.
> المهمة: **إعادة إنشاء هذا التصميم داخل بيئة مشروعك الحالية** (React / Next.js / Vue / إلخ) باستخدام أنماطها ومكتباتها المعتمدة. استعمل هذا الملف كمصدر للحقيقة — يجب أن يكفي وحده لتنفيذ التصميم دون الحاجة لحضور المحادثة الأصلية.

---

## نظرة عامة (Overview)
موقع مرجعي تفاعلي يبسّط مواد **نظام العمل السعودي**: لكل مادة نصّ رسمي + شرح مبسّط + مثال عملي. الهوية البصرية هي **«معرض طباعي» (Type Specimen)**: أرقام مواد عملاقة، خطّ ثُمانية العربي، لون أخضر زيتي وحيد، خلفية ورقية دافئة، خطوط فاصلة رفيعة وفراغ أبيض سخي.

## درجة الإتقان (Fidelity)
**عالية الدقّة (Hi-Fi):** الألوان والخطوط والمقاسات والتفاعلات نهائية. أعِد بناء الواجهة بدقّة بكسلية باستخدام مكوّنات مشروعك.

## الطباعة (Typography)

### الخطوط
- **العناوين والأرقام (Display):** `"Thmanyah Serif"` (ثُمانية سيرف) — أوزان: Light 300، Regular 400، Medium 500، Bold 700، Black 800/900.
- **النصوص والواجهة (Text):** `"Thmanyah Sans"` (ثُمانية سانس) — أوزان: Light 300، Regular 400، Medium 500، Bold 600/700، Black 900.
- ملفات الخطوط مرفقة في `fonts/` (صيغة OTF). عرّفها عبر `@font-face` (انظر `styles.css`).
- **احتياطي:** السيرف ← `'Noto Kufi Arabic', serif` · السانس ← `system-ui, sans-serif`.

### المقياس
`--t-xs:12 · sm:14 · base:16 · md:20 · lg:24 · xl:32 · 2xl:44 · 3xl:64`
`--t-4xl: clamp(72px, 13vw, 132px)` (عناوين أبطال)
`--t-mega: clamp(120px, 30vw, 360px)` (**رقم المادة العملاق** — توقيع التصميم)

- **ارتفاع السطر للنصوص العربية:** `1.9` (مهم للقراءة) · للإنجليزية `1.65`.
- الأرقام دائماً **عربية-هندية** (٠١٢٣…): استبدل `[0-9]` بـ `"٠١٢٣٤٥٦٧٨٩"`.

### الكشيدة (مميّزة لخط ثُمانية)
ميزات OpenType تُفعّل عبر `font-feature-settings`. ثلاثة مستويات (يضبطها المستخدم من لوحة «ضبط الطابع»):
- **هادئة:** `"dlig" 1, "calt" 1, "rlig" 1`
- **متوسطة (افتراضي):** `"swsh" 1, "dlig" 1, "calt" 1, "rlig" 1, "liga" 1`
- **مبالِغة:** `"swsh" 1, "ss05" 1, "dlig" 1, "calt" 1, "rlig" 1`
> أرقام المواد البطلة تستخدم فئة `.kashida` بأقصى زخرفة.

## اتجاه الصفحة (RTL)
- `dir="rtl"` على `<html>` للعربية، `ltr` للإنجليزية.
- استخدم خصائص منطقية: `inset-inline-start/end`، `margin-inline`، `padding-inline` (لا left/right ثابتة).
- **تنبيه مهم:** عناصر التحكّم المقسّمة (segmented controls) القائمة على إحداثيات المؤشّر تنعكس في RTL — استخدم أزراراً عادية بـ `onClick` بدل منطق الموضع.

## الشاشات والمكوّنات (Screens & Components)

### 1) الشريط العلوي (TopBar)
- ثابت (`position: sticky; top:0`)، ارتفاع `70px`، شفّاف يصبح ضبابياً (`backdrop-filter: blur(14px)` + حدّ سفلي) بعد تمرير `12px`.
- يمين: الشعار (مربّع `34px` بحدّ، حرف «ع» Display) + اسم الموقع.
- وسط: روابط التنقّل (الأبواب، الفهرس، حسب الموقف، الحاسبات، التعديلات، المسرد) — تختفي تحت `940px` لقائمة جوال.
- يسار: زر نصّي **«ضبط الطابع»** (قرص بحدّ) + بحث + محفوظة (بعدّاد) + لغة (ع/EN) + ثيم (شمس/قمر) + زر قائمة الجوال.
- الأزرار الأيقونية: `.act` = `40×40`، زاوية `10px`، تحويم بخلفية `--accent-tint`.

### 2) الغلاف (Cover) — الصفحة الرئيسية
- ترويسة: تسمية علوية (kicker) + خطّ فاصل + رقم المرسوم.
- عنوان `--t-4xl` بفئة `.display.kashida` (الكشيدة الدراماتيكية).
- صندوق بحث كبير قابل للنقر (يفتح overlay البحث) + أقراص «ابدأ من موقفك».
- شريط إحصاءات: ٤ أعمدة بأرقام `clamp(54px,8vw,84px)` على خلفية `--paper-2`.
- شبكة الأبواب الـ١٦ (خلايا بحدود `--hair`، رقم أخضر `40px`).
- بطاقة مادة مميّزة (specimen) برقم عملاق.

### 3) صفحة المادة (Article) — الشاشة الأهم
- مسار تنقّل (breadcrumb).
- **ترويسة الرقم:** «المادة» (تسمية) + رقم `--t-mega` بلون `--accent` (التوقيع البصري).
- شارات: `مادة مُعدَّلة` (amber)، `آخر التحديثات · سنة` (شارة حيّة بنقطة نابضة، قابلة للنقر ← التعديلات)، `نص تمثيلي` (accent).
- صفّ أزرار: حفظ / نسخ الرابط / بطاقة.
- **النص الرسمي:** صندوق `--paper-2` بحدّ يمين `3px` لون `--ink`، خط `clamp(18,2.3vw,22)` بارتفاع سطر `2`. (مع كلمات مسرد تظهر تلميحاتها عند التحويم).
- زرّ «عرض النص الأصلي قبل التعديل» (للمواد المعدّلة) يفتح صندوق amber.
- **«ببساطة»:** أيقونة دائرية + شرح مبسّط.
- **«مثال عملي»:** بطاقة بعمودين (الموقف | النتيجة بخلفية خضراء)، وزر «جرّب الحاسبة» إن وُجدت.
- كلمات مفتاحية + مواد ذات صلة (أقراص).
- تنقّل سابق/تالي + تنبيه قانوني (صندوق متقطّع).
- حالة `pending`: رقم رمادي عملاق + «هذه المادة قيد الإدخال».

### 4) الأبواب / الفصل / الفهرس
- قائمة صفوف: رقم باب عملاق + عنوان + عدّاد، تحويم بخلفية خضراء.
- شبكة مواد الفصل: مربّعات `1:1`، المُدخَلة بنقطة خضراء والبقية باهتة.
- الفهرس: أقراص تصفية حسب الباب + صفوف مواد.

### 5) حسب الموقف (Scenarios)
- بطاقات (أيقونة دائرية + عنوان + وصف + عدد مواد). صفحة تفصيل تسرد المواد + زر الحاسبة.

### 6) الحاسبات (Calculators)
ثلاث: مكافأة نهاية الخدمة (م٨٤/٨٧)، الأجر الإضافي (م١٠٧)، مدة الإشعار (م٧٥).
- تخطيط عمودين: نموذج الإدخال (يسار) + بطاقة النتيجة الخضراء اللاصقة (`position: sticky`) بالرقم الكبير + رابط المادة المرجعية + تنبيه «تقديري غير ملزم».
- منطق نهاية الخدمة: نصف شهر/سنة لأول ٥ سنوات + شهر/سنة بعدها؛ الاستقالة: <٢ لا شيء، ٢–٥ ثلث، ٥–١٠ ثلثان، ≥١٠ كامل.

### 7) المسرد / خط التعديلات / المحفوظة / البحث / بطاقة المشاركة
- **المسرد:** صفوف مصطلح/تعريف. التعريفات نفسها تظهر كتلميحات (`.gloss` + `.gloss-pop`) داخل نصوص المواد.
- **خط التعديلات:** خط زمني عمودي بعُقد؛ أحدث عقدة مميّزة؛ روابط مواد قابلة للنقر لكل تعديل (ربط ثنائي مع شارة «آخر التحديثات»).
- **المحفوظة:** من `localStorage` (`ll_bookmarks`).
- **البحث:** overlay ضبابي ملء الشاشة، بحث فوري يتجاهل التشكيل، تمييز المقطع المطابق.
- **بطاقة المشاركة:** بطاقة `4:5` داكنة + رقم عملاق أخضر، تُنزَّل كـ **PNG حقيقي ١٠٨٠×١٣٥٠** مرسوم على Canvas (انظر `renderCardBlob` في `app.jsx`) — تشكيل عربي سليم، بلا مكتبات خارجية.

## التفاعلات والحركة (Interactions & Motion)
- **ظهور العناصر:** فئة `.reveal` — **حرّك الإزاحة فقط (`translateY`) لا الشفافية** (لتجنّب اختفاء المحتوى عند تجمّد ساعة الأنيميشن أو في الطباعة/تقليل الحركة).
- التحويمات: `transition: all .18–.22s ease`.
- النقطة النابضة (`.live-dot`): `@keyframes` تكبير + تلاشٍ، خلف `prefers-reduced-motion: no-preference`.
- لوحة «ضبط الطابع»: تظهر بانتقال `translateY` فقط، تُغلق بـ Esc أو النقر خارجها.

## لوحة «ضبط الطابع» (ميزة الزائر)
ثلاثة عناصر تُعيد تشكيل الإحساس، تُحفظ في `localStorage` (`ll_character`) وتُطبَّق كمتغيّرات CSS على `<html>`:
1. **اللون المميّز:** ٤ لوحات (زيتي/كحلي/طوبي/ذهبي) لكلٍّ نسخة فاتحة وداكنة → تضبط `--accent`، `--accent-deep`، والـ tints عبر `color-mix`.
2. **مقياس الأرقام البطلة:** `--num-scale` (٠٫٧–١٫٦) يضرب `--t-4xl` و`--t-mega` عبر `calc()`.
3. **حدّة الكشيدة:** تضبط `--feat-body` و`--feat-display` و`--feat-kashida`.

## إدارة الحالة (State)
- `ll_lang` (ar/en) · `ll_theme` (light/dark) · `ll_bookmarks` (مصفوفة أرقام) · `ll_character` (الكائن أعلاه) — كلها localStorage.
- التوجيه: حالة `route` بسيطة + `#/article/N` للروابط العميقة.

## الأصول (Assets)
- **الخطوط:** `fonts/thmanyah*.otf` (سيرف + سانس).
- **أيقونات التواصل:** `icons/website.svg`, `linkedin.svg`, `whatsapp.svg` — مُلوّنة بـ `currentColor` (مدمجة عبر `brandIcons.js`).
- بقية الأيقونات: SVG خطّية مرسومة في `ui.jsx` (لا مكتبة أيقونات).
- لا صور خارجية.

## ملفات التصميم المرجعية (في هذه الحزمة)
| الملف | المحتوى |
|---|---|
| `نظام العمل.html` | نقطة الدخول (ترتيب تحميل السكربتات) |
| `styles.css` | كل التوكنات + `@font-face` + المكوّنات |
| `data.jsx` | بنية البيانات (مواد، أبواب، مسرد، تعديلات، مواقف) + `toAr` |
| `ui.jsx` | الأيقونات، الشريط العلوي، التذييل، عناصر أساسية (Badge/Btn) |
| `screens1.jsx` | الغلاف + صفحة المادة + تلميحات المسرد |
| `screens2.jsx` | الأبواب/الفهرس/المواقف/الحاسبات/المسرد/التعديلات/المحفوظة/البحث |
| `app.jsx` | بطاقة المشاركة + توليد PNG + التوجيه + لوحة «ضبط الطابع» |
| `brandIcons.js` | أيقونات SVG المدمجة |
| `fonts/`, `icons/` | الأصول |

> النصوص الحالية للمواد **عيّنات تمثيلية** موسومة `sample: true` (والمواد غير المُدخلة `status: "pending"`) — استبدلها بالنصوص الرسمية. البنية في `data.jsx` جاهزة لذلك.
