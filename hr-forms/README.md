# نماذج إدارة الموارد البشرية الموحدة — البسامي القابضة

نظام نماذج موحد بلغة تصميم تحريرية خاصة، ثوابته من الهوية: **الشعار وألوان العلامة** فقط. متوافق مع Microsoft Word، عربي بالكامل وباتجاه من اليمين لليسار.

## الملفات الجاهزة (`forms/`)

| الرقم | النموذج |
|---|---|
| HR-F-000 | القالب الموحد للنماذج (الأساس لأي نموذج جديد) |
| HR-F-001 | نموذج طلب توظيف |
| HR-F-002 | نموذج الوصف الوظيفي |
| HR-F-003 | نموذج تحديد الاحتياج من القوى العاملة |
| HR-F-004 | نموذج العرض الوظيفي |
| HR-F-005 | نموذج تحديد الاحتياجات التدريبية |

## اللغة التصميمية

- **غلاف الصفحة الأولى**: شريط داكن بأخضر الأعماق `#043D20` يحمل الشعار الأبيض المعكوس واسم النموذج بخط كبير، يغلقه خيط ذهبي `#C8A45C` رفيع، ثم سطر بيانات النموذج (الرقم · الإصدار · التاريخ · الصفحة) بفواصل ذهبية.
- **الصفحات التالية**: شريط نحيف داكن باسم النموذج ورمزه — حضور للهوية بلا تكرار للغلاف.
- **عناوين الأقسام**: رقم «شبحي» كبير بالأخضر الناعم `#BEE9D1` بجوار العنوان الغامق، فوق خيط ذهبي ممتد.
- **الحقول**: تسمية صغيرة فوق **خط تعبئة** أخضر — بلا صناديق مغلقة، فراغ مريح للكتابة اليدوية.
- **الجداول**: أسلوب تحريري — ترويسة فوق خيط أخضر سميك، وصفوف بخيوط أفقية ناعمة فقط، وصفوف الإجمالي بتعبئة `#E8F5ED`.
- **صناديق الإقرارات**: خلفية همسية `#F4FAF6` بشريط جانبي ذهبي.
- **الاعتمادات**: أعمدة حرة متجاورة (إعداد / مراجعة / اعتماد) بخط علوي أخضر وخطوط للاسم والتوقيع والتاريخ.
- **التذييل**: خيط فاصل ناعم — الجهة يمين، «سري — للاستخدام الداخلي» وسطاً، والترقيم يساراً (بالأرقام العربية الشرقية عند الفتح في Word).

الخط **Dubai** (مع Arial للرموز اللاتينية) — متوفر افتراضياً في Windows فلا ينهار التنسيق عند المشاركة.

## إنشاء نموذج جديد

الطريقة السريعة: انسخ ملف `HR-F-000` وعدّل الاسم والرمز ثم ركّب الأقسام.

الطريقة البرمجية: أضف تعريف النموذج في `build.js` (انظر النماذج الموجودة كأمثلة) ثم:

```bash
npm install
npm run build   # يكتب ملفات .docx في forms/
```

## البنية

```
hr-forms/
├── assets/           الشعار بنسختيه (الأساسية والمعكوسة) من دليل الهوية
├── lib/brand.js      ثوابت الهوية: الألوان، الخط، الهوامش
├── lib/components.js المكوّنات المشتركة (غلاف، أقسام، حقول، جداول، اعتمادات…)
├── build.js          تعريفات النماذج الستة
└── forms/            ملفات .docx الجاهزة
```
