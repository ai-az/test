# نماذج إدارة الموارد البشرية الموحدة — البسامي القابضة

نظام نماذج موحد مبني على دليل الهوية البصرية للمجموعة (الإصدار ١٫٠)، متوافق مع Microsoft Word، عربي بالكامل وباتجاه من اليمين لليسار.

## الملفات الجاهزة (`forms/`)

| الرقم | النموذج |
|---|---|
| HR-F-000 | القالب الموحد للنماذج (الأساس لأي نموذج جديد) |
| HR-F-001 | نموذج طلب توظيف |
| HR-F-002 | نموذج الوصف الوظيفي |
| HR-F-003 | نموذج تحديد الاحتياج من القوى العاملة |
| HR-F-004 | نموذج العرض الوظيفي |
| HR-F-005 | نموذج تحديد الاحتياجات التدريبية |

## ما الذي يجعلها «موحدة»؟

كل نموذج يُركَّب من المكوّنات نفسها المعرّفة في `lib/components.js`:

- **ترويسة موحدة**: الشعار يمين (٣٫٥ سم)، اسم المجموعة والإدارة واسم النموذج وسطاً، وبطاقة بيانات النموذج يساراً (رقم النموذج، الإصدار، تاريخ الإصدار، الصفحة)، يليها الشريط الأخضر بسماكة ٢ نقطة.
- **شريط قسم مرقّم**: شارة رقمية على أخضر الأعماق `#043D20` برقم ذهبي `#C8A45C` + عنوان أبيض على الأخضر البسامي `#0C8643`.
- **شبكة حقول**: تسميات على خلفية `#E8F5ED` بنص أخضر داكن، وخلايا تعبئة بيضاء بإطارات `#C9D1CD`.
- **جداول القوائم**: ترويسة خضراء بنص أبيض وصفوف بديلة `#F4FAF6` — وفق مواصفة جداول الوورد في الدليل.
- **صندوق الإقرارات**: خلفية `#E8F5ED` مع شريط جانبي أخضر — وفق مواصفة الاقتباسات.
- **كتلة الاعتمادات**: الصفة / الاسم / المسمى الوظيفي / التوقيع / التاريخ.
- **تذييل موحد**: الجهة يمين، «سري — للاستخدام الداخلي» وسطاً، ترقيم الصفحات يساراً بالأرقام العربية الشرقية.

الخط: **Dubai** (بديل المكتب المعتمد في الدليل، مع Arial للرموز اللاتينية) — الهوامش A4: ‏٢٫٥ سم من كل جهة و٣ سم من اليمين للتجليد.

## إنشاء نموذج جديد

الطريقة السريعة: انسخ `HR-F-000 القالب الموحد.docx` وعدّل الاسم والرقم في الترويسة ثم ركّب الأقسام.

الطريقة البرمجية: أضف تعريف النموذج في `build.js` (انظر النماذج الموجودة كأمثلة) ثم:

```bash
npm install
npm run build   # يكتب ملفات .docx في forms/
```

## البنية

```
hr-forms/
├── assets/          الشعار (الأساسي والمعكوس) مستخرجان من دليل الهوية
├── lib/brand.js     ثوابت الهوية: الألوان، الخط، الهوامش
├── lib/components.js المكوّنات المشتركة (ترويسة، أقسام، جداول، اعتمادات…)
├── build.js         تعريفات النماذج الستة
└── forms/           ملفات .docx الجاهزة
```
