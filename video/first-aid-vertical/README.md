طولي متحرك 9:16 بنفس الهوية والخطوط والألوان.

| الصوت | بدون |

## الهوية المستخرجة من الملف الأصلي

الملف الأصلي مُصدَّر من Canva وكل صفحة فيه صورة نقطية واحدة (6000×3375) بلا خطوط
مضمَّنة، لذلك أُعيد بناء كل شاشة نصًّا حيًّا مع مطابقة الخط والألوان بصريًّا.

**الخطوط**

- العناوين: **Zain** — طابقت أشكال الحروف في الأصل (نهايات مشطوفة، عين زاويّة، ياء منسابة).
- المتن: **IBM Plex Sans Arabic** — طابقت تركيبة «في» و«الطارئة» في فقرات الأصل.
- ملاحظة: خط Zain لا يحوي مجسّمات الأرقام العربية‑الهندية ويستبدلها بالأرقام
  اللاتينية، لذلك تُرسم كل الأرقام (١٢٣٤٥ ، ٩١١ ، ٩٩٧) بخط IBM Plex.

## البناء

المحرك يرسم كل إطار من دالة زمنية واحدة `window.__render(t)` بدل CSS animations،
فيخرج الفيديو مطابقًا تمامًا في كل تشغيل.

```bash
pip install playwright pillow          # Chromium مطلوب أيضًا
python3 build/assemble.py              # يولّد build/video.html بخطوط وأصول مضمّنة
python3 build/render.py                # 2880 إطار JPEG في build/frames/
bash    build/encode.sh                # يُخرج first-aid-vertical.mp4
```

`build/render.py` يتوقع Chromium في `/opt/pw-browsers/chromium-1194/chrome-linux/chrome`،
عدّل `executable_path` حسب بيئتك.
