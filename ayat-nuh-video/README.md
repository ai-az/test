# فيديو موشن جرافيك — سورة نوح (الآيات ١٠–٢٠)

مشروع [Remotion](https://www.remotion.dev) يُنتج فيديوًا رأسيًا (1080×1920، 30 إطار/ث، ≈ 61 ثانية)
يعرض الآيات ١٠ إلى ٢٠ من سورة نوح كلمةً كلمة، مع رسوم متحركة لكل مشهد تعبّر عن معنى الآية.

## التشغيل

```bash
npm install
npm run dev          # فتح Remotion Studio للمعاينة والتعديل
npx remotion render AyatNuh out/ayat-nuh.mp4   # تصدير الفيديو
```

## بنية المشروع

| الملف | الوظيفة |
| --- | --- |
| `src/Root.tsx` | تسجيل التركيب الرئيسي `AyatNuh` وكل مشهد على حدة داخل مجلد `AyatNuh-Scenes` |
| `src/AyatNuh.tsx` | ترتيب المشاهد عبر `TransitionSeries` مع انتقال تلاشي (20 إطارًا) بين كل مشهدين |
| `src/components/VerseText.tsx` | ظهور نص الآية كلمةً كلمة مع علامة رقم الآية ﴿﴾ |
| `src/components/Background.tsx` | خلفية ليلية متدرّجة مع نجوم تتلألأ، جسيمات ذهبية طافية، ونقش هندسي إسلامي خافت |
| `src/components/art.tsx` | أدوات الرسم الخطّي: `DrawPath` (خط يُرسم تدريجيًا)، `Rosette` (نجمة ثمانية)، ومرشّحات التوهّج |
| `src/scenes/*.tsx` | مشهد لكل آية أو زوج آيات |
| `src/fonts.ts` | تحميل خط Amiri Quran (النص القرآني) وReem Kufi (العناوين) من `public/fonts` |

## المشاهد

| المشهد | المدة | الفكرة البصرية |
| --- | --- | --- |
| المقدمة | 110 إطار | نجمة ثمانية تُرسم خطًا خطًا حول عنوان السورة |
| الآية ١٠ | 180 | أشعة نور ناعمة ونجمة ثمانية متوهّجة وشرارات صاعدة (المغفرة) |
| الآية ١١ | 180 | غيوم مرسومة بخط ذهبي، مطر بطبقتي عمق، وتموّجات على الأرض |
| الآية ١٢ | 240 | ثلاث نخلات تُرسم خطًا خطًا بسعفها، ثم نهر من موجات متحركة |
| الآيتان ١٣–١٤ | 240 | حلقات نابضة، ثم أطوار القمر السبعة من الهلال إلى البدر (أطوارًا) |
| الآية ١٥ | 200 | سبع قباب متحدة المركز تُرسم تباعًا مع غبار نجمي بينها |
| الآية ١٦ | 210 | هلال يُرسم ويتوهّج مع نجيمات، ثم شمس بهالة وأشعة دوّارة |
| الآيتان ١٧–١٨ | 260 | نباتات خطّية تنبت من الأرض، تغوص فيها، ثم تُخرَج مجددًا |
| الآيتان ١٩–٢٠ | 260 | ثلاث طبقات من التلال تنبسط، ثم سبيل ذهبي يُرسم ويسلكه ضوء متحرك |
| الخاتمة | 120 | «صدق الله العظيم» داخل النجمة الثمانية |

## التعديل

كل مشهد مسجّل كتركيب مستقل، فيمكن فتحه وحده في Studio وتعديل التوقيتات والألوان مباشرة.
لتغيير مدة مشهد عدّل `durationInFrames` في `src/AyatNuh.tsx` ثم حدّث مجموع الإطارات في `src/Root.tsx`
(المجموع − 20 × عدد الانتقالات).
