# فيديو موشن جرافيك — سورة نوح (الآيات ١٠–٢٠)

مشروع [Remotion](https://www.remotion.dev) يُنتج فيديوًا رأسيًا (1080×1920، 30 إطار/ث، ≈ 61 ثانية)
يعرض الآيات ١٠ إلى ٢٠ من سورة نوح كلمةً كلمة، مع رسوم متحركة لكل مشهد تعبّر عن معنى الآية.

## التشغيل

```bash
npm install
npm run dev          # فتح Remotion Studio للمعاينة والتعديل
npx remotion render AyatNuh out/ayat-nuh.mp4   # تصدير الفيديو
```

## بنية المشروع

| الملف | الوظيفة |
| --- | --- |
| `src/Root.tsx` | تسجيل التركيب الرئيسي `AyatNuh` وكل مشهد على حدة داخل مجلد `AyatNuh-Scenes` |
| `src/AyatNuh.tsx` | ترتيب المشاهد عبر `TransitionSeries` مع انتقال تلاشي (20 إطارًا) بين كل مشهدين |
| `src/components/VerseText.tsx` | ظهور نص الآية كلمةً كلمة مع علامة رقم الآية ﴿﴾ |
| `src/components/Background.tsx` | خلفية ليلية متدرّجة مع نجوم تتلألأ |
| `src/scenes/*.tsx` | مشهد لكل آية أو زوج آيات |
| `src/fonts.ts` | تحميل خط Amiri Quran (النص القرآني) وReem Kufi (العناوين) من `public/fonts` |

## المشاهد

| المشهد | المدة | الفكرة البصرية |
| --- | --- | --- |
| المقدمة | 110 إطار | عنوان السورة ونطاق الآيات مع زخرفة ذهبية |
| الآية ١٠ | 180 | أشعة نور تتسع وتدور (الاستغفار والمغفرة) |
| الآية ١١ | 180 | غيوم تنزل ومطر غزير متواصل (مدرارًا) |
| الآية ١٢ | 240 | نخيل ينمو ونهر يجري (الجنات والأنهار) |
| الآيتان ١٣–١٤ | 240 | دوائر تكبر تباعًا على خط (أطوارًا) |
| الآية ١٥ | 200 | سبع طبقات متحدة المركز تظهر واحدة تلو الأخرى |
| الآية ١٦ | 210 | هلال مضيء ثم شمس بأشعة دوّارة |
| الآيتان ١٧–١٨ | 260 | نبات ينبت من الأرض، يعود فيها، ثم يُخرَج مجددًا |
| الآيتان ١٩–٢٠ | 260 | أرض تنبسط ثم تُرسَم عليها سُبُل متعرّجة |
| الخاتمة | 120 | «صدق الله العظيم» |

## التعديل

كل مشهد مسجّل كتركيب مستقل، فيمكن فتحه وحده في Studio وتعديل التوقيتات والألوان مباشرة.
لتغيير مدة مشهد عدّل `durationInFrames` في `src/AyatNuh.tsx` ثم حدّث مجموع الإطارات في `src/Root.tsx`
(المجموع − 20 × عدد الانتقالات).
