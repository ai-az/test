# المرجع التفاعلي لنظام العمل السعودي

موقع تعريفي تفاعلي يبسّط مواد **نظام العمل** السعودي (المرسوم الملكي م/٥١) عبر شرحٍ
مختصر ومثالٍ عملي لكل مادة — بهوية تصميم تحريرية من نوع **type specimen** (Hallmark · Specimen).

> **تنويه:** الموقع لأغراض تعريفية فقط ولا يُعدّ استشارة قانونية. النص الرسمي الساري هو
> المعتمد. النصوص المبسّطة والأمثلة من إعداد المنصّة ومُوسَّمة بوضوح كشرح غير رسمي.

## التشغيل

```bash
npm install
npm run dev      # خادم تطوير
npm run build    # بناء الإنتاج
npm run preview  # معاينة بناء الإنتاج
```

## التقنيات

- **React + Vite** — تطبيق صفحة واحدة سريع.
- **Tailwind CSS v4** + طبقة رموز تصميم (`src/styles/tokens.css`) — هوية Specimen.
- **React Router** — التنقّل بين الغلاف والأبواب والمواد.
- **خطوط عربية:** Noto Kufi Arabic (عناوين/أرقام display) + IBM Plex Sans Arabic (نصوص).
- دعم **RTL** أصيل + تبديل عربي/إنجليزي + وضع ليلي.
- المفضّلة تُحفظ في `localStorage` (بدون حسابات أو خادم).

## آلية إدخال المحتوى (٢٤٥ مادة)

طبقة البيانات مفصولة عن الكود في `src/data/`:

- `chapters.js` — الأبواب والفصول (مكتمل ومُتحقَّق منه).
- `articles.js` — المواد، ككائن مفتاحه رقم المادة، وفق `article-template.json`.

**لإضافة دفعة مواد:** زوّدني بالنصوص الرسمية (نسخاً حرفياً من المصدر)، وأُدخِلها وفق
القالب. كل مادة غير مُدخَلة تبقى `status: "pending"` ولا يُؤلَّف لها محتوى.

النصوص الرسمية الحالية مُستخرَجة من النص الموحّد الرسمي (HRSD/HRDF) وطُبّع ترميزها،
وتبقى المراجعة النهائية على
[المصدر الرسمي](https://laws.boe.gov.sa/boelaws/laws/lawdetails/08381293-6388-48e2-8ad2-a9a700f2aa94/1).
